プライバシーポリシー

山ノ言葉（山ノ言葉醸造所の業務用 Mac アプリ）　制定 2026年10月11日

1. 取得する情報

アプリは、利用者が許可した Gmail アカウントから、読み取り専用の権限（https://www.googleapis.com/auth/gmail.readonly）で次の情報を取得します。

  • PDF が添付されたメールの差出人・件名・Message-ID・受信日時
  • 利用者がアプリに登録した取引先から届いたメールの、PDF の添付ファイル

メールの本文は保存しません。メールを送る・消す・変えることはしません。

2. 使い方

取得した PDF は、受け取ったままの状態で納品書・請求書として保管し、仕入の記録の下書きを作るためだけに使います。PDF の文字は Mac の中で読み取ります。

3. 保存する場所

取得した情報は、利用者の Mac の中だけに保存します。Google へのログインの鍵は、Mac のキーチェーンに保存します。アプリの運営者がサーバーで情報を受け取ることはありません。

4. 第三者への提供

取得した情報を、第三者（AI のサービスを含みます）に販売・提供・送信しません。ただし、利用者が請求書の支払いを承認したときに限り、その請求書の PDF を、利用者自身の Notion のワークスペースに支払いの記録として添付します。

5. Google API のデータの扱い

アプリが Google API から受け取った情報の使い方と移転は、Google API Services User Data Policy（Limited Use の要件を含みます）に従います。

6. 許可の取り消し

アプリの「設定 › Gmail」でアカウントを外すと、Google への許可を取り消します。Google アカウントの「サードパーティ製のアプリとサービス」からも取り消せます。取り消したあとも、すでに保管した書類は Mac の中に残ります。帳簿の証拠として保存が必要なためです。

7. お問い合わせ

Google のログイン画面に表示されるサポート用のメールアドレスまで、ご連絡ください。

Privacy Policy (English summary)

With read-only Gmail access (gmail.readonly), the app reads the sender, subject, Message-ID and date of mail with PDF attachments, and downloads the PDF attachments of mail from suppliers registered in the app. It keeps them on the user's Mac only, to file delivery notes and invoices and draft purchase records. Message bodies are not stored, and mail is never sent, deleted or changed. Nothing is sold, shared or sent to third parties (including AI services), except that when the user approves an invoice for payment, that invoice's PDF is attached to the user's own Notion workspace. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked in the app (Settings › Gmail) or in the Google Account's third-party apps page.
